Dúvidas frequentes

Perguntas que você pode ter

Preciso de internet para usar o Mestre PDV? +
Não. O Mestre PDV foi desenvolvido para funcionar 100% offline, diretamente no seu computador com Windows 10 ou superior (64 bits). Não é necessário navegador, servidor externo, Python ou banco de dados separado.
Como funciona a entrega? +
A entrega é imediata. Assim que o pagamento for confirmado, o acesso ao arquivo é liberado na plataforma para download. A instalação é simplificada: basta colocar o arquivo do programa em uma pasta do computador e executá-lo.
Quais formas de pagamento posso registrar nas vendas? +
Dinheiro, Pix, cartão de débito, cartão de crédito e cartão presente. Também é possível dividir o pagamento de uma mesma venda entre diferentes formas, com cálculo automático de troco.
Consigo imprimir cupons? +
Sim. Você pode personalizar o cabeçalho e o rodapé com os dados do estabelecimento e imprimir os cupons em impressoras reconhecidas pelo Windows. Também é possível gerar cupons em PDF, caso prefira não usar impressora.
Meus dados ficam salvos onde? +
Todos os dados — cadastros, vendas, caixa, estoque e relatórios — ficam armazenados no próprio computador. O sistema ainda traz uma ferramenta integrada de backup para você gerar cópias de segurança quando quiser.
Serve para quais tipos de negócio? +
É ideal para bares, lanchonetes, cafeterias e outros estabelecimentos com atendimento no balcão ou pedidos de mesa: lanches rápidos, cafés, bebidas, porções, doces e salgados.
